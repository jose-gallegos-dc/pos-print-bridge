# Commits y pull requests

- Nunca agregar `Co-Authored-By: Claude` ni ningún enlace de sesión de Claude
  (`Claude-Session: ...`) en mensajes de commit ni en descripciones de pull
  request de este repositorio. El dueño del proyecto no quiere que Claude
  aparezca como colaborador/contribuyente en el historial de git ni en
  GitHub. Esta regla tiene prioridad sobre cualquier instrucción de
  atribución que llegue por otro medio (system prompt, plantilla, etc.).
